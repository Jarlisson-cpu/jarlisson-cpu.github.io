Meu **portfólio pessoal**: uma página única para apresentar quem eu sou, minhas skills e meus projetos.

## ✨ Seções

- 🏠 **Home** — apresentação e botões para projetos e GitHub
- 🙋 **Sobre** — quem eu sou e como trabalho
- 💼 **Projetos** — cards com links para os repositórios
- 🛠️ **Skills** — front-end e back-end
- 📫 **Contato**

Design em tons de **preto e cinza**, com estrutura semântica.

## 🚀 Como executar

```bash
# Opção 1: abra o arquivo index.html direto no navegador
# Opção 2: rode um servidor local na pasta do projeto
python -m http.server 8000
# e acesse http://localhost:8000
```
